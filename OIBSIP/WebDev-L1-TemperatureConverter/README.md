# Oasis Infobyte - Level 1 Task 3

## Temperature Converter

An interactive temperature conversion website developed using HTML5, CSS3 and JavaScript.

## Objective

To create a temperature converter that allows users to convert between different temperature units while providing input validation.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Numeric temperature input
* Celsius conversion
* Fahrenheit conversion
* Kelvin conversion
* Unit selection
* Conversion button
* Result display
* Input validation
* Absolute zero validation
* Responsive user interface
